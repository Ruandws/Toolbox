# Nota de Atualização: Implementação da detecção de login falho e diminuição do timeout (feat)
Data: 02 de junho de 2026, às 17:22

## O que foi feito
- **Aprimoramento da Autenticação em `consultor_sti.py`**
  - Implementada constante `LOGIN_FAILED_WARNING_SELECTOR` com seletores para capturar caixas de alerta ou aviso de erro do sistema (toasts, alertas, etc).
  - Implementado regex `LOGIN_FAILED_WARNING_PATTERN` para buscar mensagens com palavras-chave indicando falha de login (ex. login inválido, senha incorreta, bloqueado, expirado).
  - Adicionadas funções `get_login_failed_warning_locator` e `get_visible_login_failed_warning_text` para capturar os alertas de erro exibidos pela página web.
  - Refatorada a função `wait_for_login_completion`: removida a espera estática fixa; agora implementa polling com `time.monotonic()` que checa ativamente a aparição de um aviso de falha ou o sucesso da autenticação.
  - Diminuição do timeout padrão de espera no login (`LOGIN_COMPLETION_TIMEOUT_MS`) de 15000 para 6000 milissegundos, agilizando o processo em caso de erro.
- **Melhorias de Interface em `ui_consultor.py`**
  - Aprimorado o tratamento de erro em `run_playwright_task`: se a exceção começar com "Login falhou:", a interface exibe a mensagem de forma direta, melhorando o feedback e evitando prefixos de erro genéricos.
