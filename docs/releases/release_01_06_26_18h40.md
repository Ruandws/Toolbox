# Nota de Atualização: Refatoração : Seletores e Esperas Robustas (refactor)
Data: 01 de junho de 2026, às 18:40

## O que foi feito
- **Implementação de Seletores e Lógica de Espera Robusta no Consultor STI**
  - Implementada nova função `get_search_input_locator` para centralizar a localização do campo de pesquisa.
  - Implementada nova função `get_search_button_locator` para localizar o botão principal de pesquisa.
  - Implementada nova função `get_search_loading_button_locator` para localizar o estado de carregamento ("Pesquisando...").
  - Implementada nova função `get_no_user_found_locator` para isolar a localização da mensagem de "Nenhum usuário encontrado".
  - Implementada nova função `get_search_result_rows_locator` para obter os resultados da tabela de pesquisa.
  - Implementada nova função `wait_for_search_loading_cycle` que gerencia ativamente o tempo de espera pelo ciclo de _loading_ do sistema alvo.
  - Refatorada a função `wait_for_search_response` para utilizar lógicas combinadas (resultado na tabela ou mensagem de ausência) e aprimorar a detecção.
  - Atualizadas as constantes do sistema (ex: `SEARCH_INPUT_PLACEHOLDER`) para alinhar estritamente com os textos da UI alvo.

## Observações
  - O código agora está mais resiliente contra oscilações de tempo de resposta do STI.
  - O código está assombrosamente mais veloz em sua execução. 
  - Realizei também manualmente os mais variados testes de tipos de CPF inválidos (Dígito a mais, dígito a menos, caracteres especiais, cpf com um só dígito, cpf com 20 dígitos...) e todos foram devidamente identificados e tratados.
