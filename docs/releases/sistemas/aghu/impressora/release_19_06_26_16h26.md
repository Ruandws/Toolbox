# Release: Modulo Impressoras AGHU - Switch de Ambiente de Producao para Homologacao
**Data:** 19 de junho de 2026, 16h26

---

## 1. Nova Funcionalidade
- Adicionado Switch de Ambiente (Produção / Homologação) na interface `ui_alignprinterAGHU.py`.
- Adicionado alerta de sistema para o Ambiente de Produção, indicando o risco de execução produtiva.

## 2. Refatoracao
- `autenticador.py` exporta `AGHU_URL_HOMOLOGACAO` em adição à constante padrão de produção.
- `ui_alignprinterAGHU.py` monta o mapa de URLs de ambiente e repassa a escolha ao Maestro como `url_aghu`.
- `PrinterAGHU.py` atualizou os métodos (`fazer_login`, `trocar_aba_aghux`, `navegar_ate_modulo`, `processar_computadores`) para aceitarem a `url_aghu` fornecida. Garantindo que retries e retornos do Almoxarifado em Clean State mantenham a janela apontada para o ambiente inicialmente escolhido.

## 3. Documentação
- RFCs `RFC_001_printerAghu.md` e `RFC_003_ui_alignprinterAghu.md` atualizadas com as implementações de switch e a injeção da variável `url_aghu`.

## Observações
- Não foram identificadas vulnerabilidades ou falta de tratamentos de exceção. A url padrão foi adequadamente declarada e implementada como fallback em `obter_url_ambiente_aghu`.
