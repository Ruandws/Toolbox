# Release: Módulo Impressoras AGHU — Refatoração de Autenticação
**Data:** 15 de junho de 2026, 15h28

---

## 1. Centralização da Autenticação

- Os arquivos `AddPrinterAGHU.py`, `PrinterAGHU.py` e `ui_alignprinterAGHU.py` foram refatorados para delegar o login ao módulo centralizado `autenticador.py`, removendo toda a lógica de autenticação inline.
- A função `fazer_login` de `PrinterAGHU.py` e `AddPrinterAGHU.py` agora delega ao wrapper central `fazer_login` do `autenticador.py`.
- A função `trocar_aba_aghux` foi atualizada para usar `autenticar_aghu_page`, autenticando com uma instância de `Page` do Playwright já existente.
- A função `autenticar_aghu` foi mantida para uso em testes isolados.

---

## 2. Refatoração do Autenticador (`autenticador.py`)

- **`ResultadoLogin` (dataclass):** retorno estruturado com os status tipados `sucesso`, `sessao_ativa`, `credenciais_invalidas`, `timeout` e `erro`.
- **`autenticar_aghu_page`:** nova função que autentica usando uma `Page` Playwright já existente.
- **`exigir_login_valido`:** novo wrapper que garante login válido ou lança exceção.
- **`fazer_login`:** wrapper central que encapsula o fluxo completo de autenticação.
- Seletores com fallback encadeado para resiliência a mudanças de layout.
- Detecção de sessão ativa antes de tentar novo login.

---

## 3. Configuração de URL por Variável de Ambiente

- A constante `AGHU_URL_PRODUCAO` (hardcoded) foi removida de `PrinterAGHU.py` e `ui_alignprinterAGHU.py`.
- A URL do AGHU é agora definida como `AGHU_URL` no `autenticador.py`, configurável via variável de ambiente `AGHU_URL` (com compatibilidade retroativa para `URL_LOGIN_AGHU`).
- `PrinterAGHU.py` e `ui_alignprinterAGHU.py` passam a importar `AGHU_URL` diretamente do autenticador.
