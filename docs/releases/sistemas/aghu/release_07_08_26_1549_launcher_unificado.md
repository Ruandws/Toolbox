- `sistemas/aghu/concessor_aghu.py`: `PROJECT_DIR` deixa de ser sempre `BASE_DIR.parents[1]` e passa a ser `BASE_DIR if getattr(sys, "frozen", False) else BASE_DIR.parents[1]`.
