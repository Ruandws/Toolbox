**Sistema:** aghu
**Data:** 2026-07-02
**Arquivo:** sistemas/aghu/criar_usuario_aghu.py

**O que mudou:**
- `criar_usuario_aghu.py` adicionou `_normalizar_nome_completo` para colapsar sequências de espaços, tabs e quebras de linha antes de remover espaços laterais do nome completo.
- `_normalizar_usuario_importacao` passou a preencher `UsuarioImportacao.nome_completo` usando `_normalizar_nome_completo`, em vez de apenas aplicar `strip()` ao valor textual.
- `_preparar_usuario_importacao` passou a validar um `UsuarioImportacao` intermediário que preserva `login` e `email` originais, mas usa `nome_completo` normalizado, permitindo aceitar nomes com espaços corrigíveis sem relaxar a validação de espaços indevidos em login e e-mail.

**Observações:** Release criada para resolver o problema em que a automação em lote exibia, no relatório de saída, a mensagem "Ignorado: nome com espaços inválidos" para usuários com nomes adequadamente preenchidos. Problema resolvido.
