**O que mudou:** Adição de layout automático ao relatório XLSX (freeze panes, auto-filter, auto-fit de colunas) e simplificação do texto informativo de lote na UI.

### prorrogador_sti.py

- Novo import `get_column_letter` de `openpyxl.utils`.
- Novas constantes de layout XLSX: `XLSX_HEADER_ROW`, `XLSX_FREEZE_PANES_CELL`, `XLSX_MIN_COLUMN_WIDTH`, `XLSX_MAX_COLUMN_WIDTH`, `XLSX_COLUMN_PADDING`.
- Nova função `apply_xlsx_report_layout`: aplica freeze panes, auto-filter e auto-fit ao worksheet.
- Nova função `build_xlsx_filter_range`: monta o intervalo de filtros com base nas dimensões do worksheet.
- Nova função `autofit_xlsx_columns`: ajusta largura das colunas pelo maior conteúdo.
- Nova função `get_xlsx_cell_text_length`: calcula o tamanho visível de uma célula, lidando com múltiplas linhas.
- `write_xlsx_report` agora invoca `apply_xlsx_report_layout` antes de salvar.

### ui_prorrogador.py

- Texto do label `label_batch_info` simplificado para "Para lote, informe planilha e pasta de relatório." — removido bloco explicativo sobre colunas e comportamento interno.
