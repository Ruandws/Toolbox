### prorrogador_sti.py

#### Novas constantes
- `USER_PAGE_READY_TIMEOUT_MS`, `USER_DATE_INPUT_TIMEOUT_MS`, `USER_UPDATE_BUTTON_TIMEOUT_MS`, `USER_SAVE_RESPONSE_TIMEOUT_MS`, `USER_SAVE_CONFIRMATION_TIMEOUT_MS` — timeouts da tela de usuário.
- `USER_SAVE_REQUEST_METHODS` — conjunto de métodos HTTP aceitos para detectar resposta de salvamento.
- `USER_NOT_FOUND_SELECTOR` / `USER_NOT_FOUND_PATTERN` — seletor e padrão regex para detecção de usuário inexistente.
- `USER_SAVE_CONFIRMATION_SELECTOR` / `USER_SAVE_CONFIRMATION_PATTERN` — seletor e padrão regex para confirmação visual de salvamento.

#### Novas funções de suporte à tela de usuário
- `get_user_date_input_locator` — locator do campo de data.
- `get_user_update_button_locator` — locator do botão "Atualizar dados".
- `get_user_not_found_locator` — locator de mensagem "usuário não encontrado".
- `get_user_save_confirmation_locator` — locator de confirmação pós-salvamento.
- `wait_for_user_page_ready` — aguarda campo de data **ou** aviso de não-encontrado, sem espera fixa.
- `wait_for_user_form_ready` — aguarda campo de data e botão de atualização.
- `is_user_save_response` — filtra resposta HTTP de salvamento (POST/PUT/PATCH, status < 500).
- `wait_for_user_save_confirmation_if_available` — aguarda confirmação visual opcional pós-save.
- `click_update_and_wait_for_post_save_state` — orquestra clique em "Atualizar dados" com fallback visual e verificação de HTTP ≥ 400.

#### Refatoração de `process_user_prepared_value` - Removidas Redundâncias
- Parâmetro renomeado de `expiration_date` → `prepared_expiration_date` (semântica mais precisa).
- Removida chamada a `normalize_expiration_date` internamente (data já chega preparada).
- Substituídas esperas fixas (`wait_for_timeout`, `networkidle`) por `wait_for_user_page_ready` + `wait_for_user_form_ready` + `click_update_and_wait_for_post_save_state`.
- Remoção de locators inline (`page.get_by_role` duplicados) em favor das funções extraídas.

#### Remoção de código redundante
- `prepare_batch_user_value` removida — era um wrapper sem lógica própria; substituída por chamada direta a `prepare_user_value` em `run_batch_automation`.
- Linha duplicada `text = str(value).strip()` em `normalize_expiration_date` removida.
